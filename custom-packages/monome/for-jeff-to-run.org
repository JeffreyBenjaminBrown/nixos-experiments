* DONE Step 5 — Real =switch= + verify serialoscd runs
Step 4 dry build succeeded. The nix store already has the new system
derivation; switching just activates it.

What the script does:
1. =sudo bash ./bash/copy.sh= (idempotent, same as step 4).
2. =sudo nixos-rebuild switch --keep-failed=.
3. =systemctl --user daemon-reload= then =systemctl --user start
   serialoscd.service= — so the new unit starts now, without waiting
   for a logout.
4. Reports =systemctl --user status serialoscd= and the last 50
   lines of its journal.
5. Lists =/dev/ttyUSB*= and the binaries on PATH.
6. If =oscsend=/=oscdump= are installed (from =liblo=), sends
   =/serialosc/list= to UDP port 12002 to see if any grid is
   discovered. Otherwise skips that check quietly.

Before running: plug the monome in (it should show up as
=/dev/ttyUSB0=, same as in step 1).

* DONE Step 7 — Fix the zeroconf warning

advertise over LAN/bonjour (so network monome apps can't discover
the grid). Cause: serialosc calls =dlopen("libdns_sd.so")= at runtime
